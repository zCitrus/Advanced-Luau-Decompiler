# 📜 Credits & Acknowledgments

This project is a modernized overhaul of the original Luau bytecode decompiler architecture, updated to support contemporary bytecode revisions, modern opcodes, and readable AST reconstruction.

---

* **[zCitrus](https://github.com/zCitrus)**  
  * Maintenance, modern bytecode support (v3 to v13+).
  * Implementation of human-readable AST expression reconstruction.
  * Opcode synchronization, vector constants support, and multi-tier pipeline integration.
